# Linear-Regression-Project-
Implementing Linear Regression using Gradient Descent

The goal of this project was to understand core ML fundamentals

## Approach:
- Implemented Linear Regression from scratch using NumPy.
- Used gradient decent to minimize error/loss
- Computed gradients (dw, db) using Mean Squared Error loss
- Stored loss values during training to track convergence.
- Plotted a "Loss vs Epoch" graph using Matplotlib

## Results:
- Loss vs Epoch graph: shows that the loss decreases over time (proves that the model is learning correctly)
- Final learned eqation: Y = 1.928X + 0.271
